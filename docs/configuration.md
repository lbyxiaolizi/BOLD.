# 配置说明

[返回项目首页](../README.md) · [安装与升级](installation.md) · [密码保护指南](password-protection.md)

配置入口：登录 Typecho 后台，进入 **「控制台 → 外观 → 设置外观」**。下表列出了 `functions.php` 中定义的全部外观配置项及其内部键名；除特别注明默认值的单选项外，其余文本框与多行文本项初始均为空。

## 语言与站点资料

| 后台选项名称 | 配置键名 | 说明与默认值 |
| --- | --- | --- |
| **界面标题语言** | `languageSetting` | 可选 `en`（English，默认）或 `cn`（中文），用于控制侧边栏、评论区、提示信息等主题界面词条 |
| **站点 Logo 文字** | `logoText` | 顶部导航栏显示的站点标识文字；支持内联 HTML（例如 `BOLD<span class="text-pink-600">.</span>`） |
| **Favicon 图标 URL** | `faviconUrl` | 浏览器标签页图标地址；留空时不输出图标标签 |
| **作者名称** | `AuthorName` | 个人资料卡片中显示的作者名称（注意配置键名首字母大写） |
| **个人头像 URL** | `avatarUrl` | 侧边栏与默认独立页面个人卡片中展示的头像图片地址 |
| **个人简介** | `descriptions` | 个人资料卡片中的一句话简介或签名 |
| **GitHub 链接** | `githubLink` | 您的 GitHub 个人主页完整 URL |
| **Bilibili 链接** | `bilibiliLink` | 您的 Bilibili 个人空间完整 URL |
| **Email** | `email` | 联系邮箱地址（前端渲染时会自动补全 `mailto:` 协议前缀） |
| **ICP 备案号** | `icpNum` | 页脚展示的网站备案号（中国大陆部署站点按需填写） |
| **侧边栏作者名称** | `sidebarAuthorName` | 侧边栏个人卡片专用的作者名称；留空时自动回退使用上方的「作者名称」 |

## 资源加载与自定义代码

| 后台选项名称 | 配置键名 | 说明与默认值 |
| --- | --- | --- |
| **加载 Google Fonts 字体** | `loadGoogleFonts` | 默认 `1`（加载）；中国大陆站点或内网环境建议设为 `0`（不加载，回退使用系统字体）以避免请求阻塞 |
| **自定义头部 HTML** | `customHead` | 插入在 `</head>` 闭合前，适合注入自定义 `<style>` 样式或搜索引擎验证 `<meta>` 标签 |
| **自定义底部 HTML** | `customFooter` | 插入在 `</body>` 闭合前，适合放置网站统计脚本或自定义 `<script>` |
| **默认封面图 URL** | `defaultOgImage` | 当文章正文不含可用图片时，作为 Open Graph（`og:image`）的默认社交分享图；留空则不输出该标签 |

> **前端资源加载机制**：
> - **本地静态资源**：Tailwind CSS 与 Typography 插件已预编译为本地 `assets/css/tailwind.min.css`，图片灯箱（`view-image.min.js`）亦由主题自托管，无需联网即可工作。
> - **按需第三方资源**：Prism.js（代码高亮脚本）、tocbot（文章目录）、MathJax（数学公式）与 Mermaid（流程图）采用固定版本与 SRI 完整性校验，并仅在页面存在对应内容时按需加载。普通货币金额（如 `$9 to $29`）不会误触发 MathJax 加载。
> - 自定义样式与脚本的写法示例请参阅 [内容与页面用法](usage.md#自定义样式和脚本)；修改模板类名后的 CSS 编译流程请参阅 [开发与验证](development.md#构建样式)。

## 评论验证与赞赏设置

| 后台选项名称 | 配置键名 | 说明与默认值 |
| --- | --- | --- |
| **Turnstile Site Key** | `turnstileSiteKey` | Cloudflare Turnstile 站点公钥；需与 Secret Key **同时填写**才会启用评论人机验证 |
| **Turnstile Secret Key** | `turnstileSecretKey` | Cloudflare Turnstile 服务端密钥；用于评论提交时的后端校验 |
| **微信收款码 URL** | `wechatQrUrl` | 文章底部赞赏弹窗中的微信收款码图片地址；留空时显示占位提示 |
| **支付宝收款码 URL** | `alipayQrUrl` | 文章底部赞赏弹窗中的支付宝收款码图片地址；留空时显示占位提示 |

> **Turnstile 运行要求**：启用后，站点服务器需能发起对 Cloudflare 验证接口的出站 HTTPS 请求（优先使用 PHP `cURL` 扩展，缺失时自动回退至 PHP HTTP Stream）。若仅填写了其中一个 Key，前端验证组件与后端拦截均不会激活。

## 密码保护与订阅源

| 后台选项名称 | 配置键名 | 默认值与行为说明 |
| --- | --- | --- |
| **全站加密密码** | `postPassword` | 默认空（不启用）；设置后，所有未配置更高优先级密码的文章和页面均需验证该密码 |
| **加密分类 (用英文逗号分隔)** | `passwordProtectedCategories` | 默认空；填写需保护的分类别名（`slug`），多个别名以英文逗号分隔（如 `private,secret`） |
| **分类独立密码设置** | `categoryPasswords` | 默认空；按 `分类slug:密码` 格式每行配置一条。凡在此处配置了独立密码的分类，会自动纳入受保护分类 |
| **加密分类文章在首页的显示** | `hideProtectedCategoriesFromHome` | 默认 `0`（显示，未解锁时摘要显示保护提示）；设为 `1`（隐藏）时将在首页 SQL 查询层直接排除加密分类文章 |
| **加密分类的归档页面是否需要密码验证** | `requireCategoryArchivePassword` | 默认 `1`（需要，访问分类列表前须先验证分类密码）；设为 `0`（不需要）时公开分类列表，但单篇文章的摘要与正文保护依然生效 |
| **RSS/Atom 订阅源中的加密文章** | `protectFeed` | 默认 `1`（保护，推荐）；设为 `0` 时关闭整篇文章及受保护评论在 Feed 中的脱敏（内联隐藏块仍会被剥离） |

- **页面级密码优先级**：`文章 / 页面自定义字段 password` ＞ `分类独立密码` ＞ `全站加密密码`。
- **注意**：一旦设置了「全站加密密码」，未列入加密分类的普通文章和独立页面同样会受到全站密码保护。若仅需保护特定分类，请保持「全站加密密码」为空，并在「分类独立密码设置」中为目标分类单独配置密码。完整规则请参阅 [密码保护指南](password-protection.md)。

## 文章与页面自定义字段

在撰写文章或独立页面时，展开编辑器底部的 **「自定义字段」** 面板即可按需添加以下字段：

| 字段名称 | 推荐类型 / 取值 | 作用范围与说明 |
| --- | --- | --- |
| `password` | 字符（文本） | 为当前文章或页面设置独立访问密码（覆盖分类密码与全站密码）。默认独立页、时间轴归档与友情链接模板均遵循此门禁 |
| `hideProfile` | 字符：`1` | 在默认独立页面模板（`page.php`）中隐藏正文上方的作者个人资料卡片 |

> **与 Typecho 原生密码的区别**：自定义字段 `password` 是由 BOLD 主题接管的加密门禁，与编辑器右侧「公开度 → 密码保护」的 Typecho 原生密码相互独立。注意：使用 Typecho 原生密码保护的文章将始终被排除在公开时间轴归档之外，详见 [内容与页面用法](usage.md#时间轴归档)。
