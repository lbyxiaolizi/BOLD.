## 评论后可见

在文章或页面正文中，使用 `{hide}` 与 `{/hide}` 标签包裹需要读者评论后才能查看的内容：

```markdown
这是公开可见的正文段落。

{hide}
这部分隐藏内容需要提交评论并通过审核后才能查看。
{/hide}

这又是公开可见的正文段落。
```

### 解锁规则与权限边界

- **未登录访客（匿名评论）**：提交评论后，服务端会下发一枚有效期为 **7 天**、绑定「文章 CID + 评论 COID + 规范化邮箱」的 `HttpOnly` HMAC 签名回执 Cookie。当该条评论审核通过（`approved`）后，访客在同一浏览器（保留回执与记忆邮箱 Cookie）中即可解锁查看。
- **已登录用户**：系统直接查询当前登录账号（`authorId`）在该文章下是否存在已审核通过的评论记录。
- **文章作者**：登录后可直接查看本人所写文章中的全部 `{hide}` 内容，无需评论。

> **注意事项**：
> - 处于待审核（`waiting`）状态的评论不会立即解锁隐藏内容。若匿名回执过期（超过 7 天）、清空了浏览器 Cookie 或更换了设备 / 浏览器，访客需重新提交评论并等待审核。
> - 页面密码保护与「评论后可见」相互独立校验；若文章同时设置了页面级密码，访客需先输入密码通过页面门禁，再按上述规则解锁 `{hide}` 块。
> - 保护标记支持嵌套，但必须严格按顺序成对闭合。若出现未闭合、错序或畸形标签，解析器将采取**保密优先（Fail-Closed）**策略，从对应开启标签处截断后续公开内容。隐藏块在 Markdown 渲染前即完成剥离，块内的脚注定义与引用链接同样受保护而不会外泄。

## 密码保护内容

BOLD 主题提供四个层级的密码保护：**全站密码**、**分类密码**、**单篇文章 / 页面密码**以及**正文内联段落密码（`{password:...}`）**。

完整的配置步骤、优先级规则与语法示例请参阅 [密码保护指南](password-protection.md)，相关后台配置项见 [配置说明](configuration.md#密码保护与订阅源)。

## 特殊页面

在 Typecho 后台新建独立页面时，可在编辑器右侧的 **「自定义模板」** 下拉框中选择以下专用模板。自定义字段 `password` 对所有独立页面模板均生效。

### 时间轴归档

选择 **「Archive Timeline (时间轴归档)」** 模板（对应 `page-archive.php`）。

- 该模板会按年份与月份倒序展示全站已发布的文章列表，并根据当前访客的分类解锁状态动态展示或过滤加密分类下的文章。
- **原生密码文章过滤**：凡在 Typecho 编辑器中设置了原生非空密码的文章，将始终在 SQL 层被排除在公开时间轴之外（即使当前访客已解锁），以防止其真实标题在归档页泄露；此类文章仍可通过其固定链接单独访问。

### 友情链接

选择 **「Links (友情链接)」** 模板（对应 `page-links.php`），并在页面正文中直接使用 Markdown 无序列表编写友链：

```markdown
- [站点名称](https://example.com): 一句话站点简介
- [另一个站点](https://example.org) - 支持连字符或中文冒号分隔
- [无简介站点](https://example.net)
```

模板会自动解析列表中的超链接并渲染为新粗野主义风格的网格卡片；站点描述可省略，分隔符支持英文冒号 `:`、中文冒号 `：` 或连字符 `-`。

### 隐藏个人简介卡片

使用默认独立页面模板（`page.php`）时，页面顶部默认展示博主的个人资料卡片。若希望在特定页面（如「隐私政策」或纯文本页）中隐藏该卡片，只需在页面编辑器的「自定义字段」中添加字段 `hideProfile` 并将值设为 `1`。

## 阅读增强与扩展语法

文章与独立页面会根据正文中的标题（`h1`–`h6`）自动生成目录：桌面端在右侧展示粘性目录（Sticky TOC），移动端则在正文上方提供可折叠目录。此外，主题内置了自托管图片灯箱，并支持按需加载代码高亮、数学公式与 Mermaid 图表。

### 代码高亮（Prism.js）

使用带语言标识的 Markdown 围栏代码块即可触发语法高亮与一键复制按钮：

````markdown
```php
echo 'Hello, BOLD.';
```
````

### 流程图与图表（Mermaid）

使用 `mermaid` 语言标识的围栏代码块即可在前端渲染图表：

````markdown
```mermaid
graph LR
    A[开始阅读] --> B[解锁隐藏内容]
```
````

### 数学公式（MathJax）

支持成对的块级公式 `$$...$$`、LaTeX 定界符 `\(...\)` 与 `\[...\]`，以及包含数学特征的行内公式 `$...$`（纯数字价格如 `$9 to $29` 会被智能忽略，避免误加载 MathJax 脚本）。

## 自定义样式和脚本

若只需微调少量样式或挂载统计脚本，可直接通过后台「设置外观」注入，无需修改主题源码：

在 **「自定义头部 HTML」**（`customHead`）中添加自定义 CSS：

```html
<style>
/* 在此编写自定义样式 */
</style>
```

在 **「自定义底部 HTML」**（`customFooter`）中添加自定义 JavaScript：

```html
<script>
// 在此编写自定义脚本或统计代码
</script>
```

> **提示**：通过后台注入普通 CSS 无需重新编译样式。但如果你直接修改了 `.php` 模板或 `.js` 文件中的 Tailwind 工具类，请务必参照 [开发与验证](development.md#构建样式) 重新运行构建命令以生成最新的 `assets/css/tailwind.min.css`。
