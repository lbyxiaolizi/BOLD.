# 安装与升级

[返回项目首页](../README.md) · [配置说明](configuration.md) · [开发与验证](development.md)

## 环境要求

| 项目 | 要求说明 |
| --- | --- |
| **博客系统** | Typecho `1.2.1` 或兼容版本（核心集成测试以 `1.2.1` 为基准） |
| **PHP 版本** | `7.3` 及以上（历史审计与验证环境详见 [安全审计记录](../security.md)） |
| **站点密钥** | 密码保护功能依赖 Typecho 安装时自动生成的非空随机 `secret`；缺失时将拒绝签发解锁票据 |
| **Node.js / npm** | 仅在修改 Tailwind CSS 类名并重新构建样式时需要；直接部署主题无需安装 |

## 首次安装

1. 进入 Typecho 站点的 `usr/themes/` 目录并获取主题代码：

   ```bash
   git clone https://github.com/lbyxiaolizi/BOLD. BOLD
   ```

   > 若通过下载压缩包安装，解压后请将主题目录重命名为 `BOLD`，再上传至 `usr/themes/BOLD/`。

2. 核对目录结构，确保核心模板文件直接位于 `usr/themes/BOLD/` 根目录下（避免解压后多嵌套一层目录）：

   ```text
   <Typecho 根目录>/usr/themes/BOLD/
   ├── index.php
   ├── functions.php
   ├── inc/
   └── assets/
   ```

3. 登录 Typecho 后台，进入 **「控制台 → 外观」**，找到 **BOLD** 并点击「启用」。
4. 点击 **「设置外观」**，按需配置界面语言、作者资料、社交链接与安全选项并保存。完整参数说明见 [配置说明](configuration.md)。
5. 访问站点首页、文章页与独立页面，检查桌面端、移动端、暗色模式及评论功能是否正常。

> **关于阅读量统计迁移**：管理员首次打开后台「设置外观」页面时，主题会自动检测并按需在 `contents` 表中创建 `views` 字段（需数据库账号具备 `ALTER TABLE` 权限）。若尚未打开过设置页或数据库无建列权限，前台将平滑降级显示阅读量为 `0` 并跳过写入，不会影响正常浏览。

## 升级指南

1. **备份数据**：升级前请先备份当前主题目录、后台外观设置及站点数据库；若做过本地代码修改，请提前保存差异（`git diff`）。
2. **完整同步文件**：将根目录下的 `.php` 模板文件、`inc/` 目录及 `assets/` 目录一并替换。主题模板与 `inc/` 模块紧密耦合，请勿仅替换部分文件。
3. **保存外观设置**：登录后台并打开一次「设置外观」页面，核对新增配置项后点击保存（同时触发必要的字段检查与迁移）。
4. **清理缓存**：清理站点可控的整页 HTML 缓存、RSS/Atom 缓存、反向代理缓存及 CDN 缓存。
5. **回归验收**：使用未登录的隐私窗口复测密码门禁、列表摘要、订阅源脱敏、评论提交及特殊页面模板，再验证密码正确解锁后的访问表现。

## 历史版本兼容性说明

| 变更项 | 升级后的行为表现 |
| --- | --- |
| **`v2` HMAC 解锁票据** | 旧版解锁 Cookie 自动失效，访客需重新输入一次密码。新票据有效期为 **7 天**，并按单篇、分类、全站与内联段落分别隔离存储 |
| **密码表单 CSRF 保护** | 提交密码时需携带主题签发的 `bold_password_csrf` Cookie 与上下文令牌，拦截跨站伪造请求 |
| **匿名评论后可见** | 采用绑定「文章 CID + 评论 COID + 规范化邮箱」的服务端 HMAC 签名回执；升级前的历史匿名评论者需重新提交一次评论并待审核通过后方可解锁 |
| **保护标记渲染前置（1.4.3+）** | `{password:...}` 与 `{hide}` 改为在 Markdown 解析前处理，防止脚注与引用链接外泄；内联密码块标识改为基于原文偏移计算，旧版内联解锁票据可能失效 |
| **静态资源与订阅源保护** | 升级后建议在外观设置中确认 Google Fonts 开关与 RSS/Atom 订阅源保护状态（订阅源保护默认开启） |

此外，修改任意层级的密码或轮换 Typecho 站点的 `secret` 密钥，均会使对应的存量解锁票据立即失效。各版本的详细安全修复与验证范围请参阅 [安全审计记录](../security.md)。

## 常见问题排查

| 故障现象 | 排查与解决方法 |
| --- | --- |
| **后台外观列表未显示主题** | 检查 `index.php` 是否直接位于 `usr/themes/BOLD/` 下，排除解压产生多层目录或目录权限不足的问题 |
| **升级后报错提示找不到文件或函数** | 确认根目录模板、`inc/` 与 `assets/` 来自同一版本且已完整上传，未遗漏任何模块文件 |
| **修改模板中的 Tailwind 类名后未生效** | 需参照 [开发与验证](development.md#构建样式) 运行 `npm run build:css` 重新生成 `assets/css/tailwind.min.css` 并刷新浏览器 / CDN 缓存 |
| **文章阅读量始终显示为 `0`** | 使用管理员账号打开一次后台「设置外观」页面以触发 `views` 列迁移，并确认数据库账号具备建列与写入权限 |
| **输入正确密码后仍停留在密码界面** | 检查站点 `config.inc.php` 中是否包含非空 `secret`、浏览器是否允许写入 Cookie、表单是否被缓存插件缓存；建议清理上游缓存后刷新页面重试 |
| **国内访问时字体加载缓慢或阻塞** | 在后台「设置外观」中将「加载 Google Fonts 字体」设为「不加载（使用系统字体）」 |

> **生产环境建议**：启用密码保护的站点务必部署于 **HTTPS** 环境，并确认反向代理或 CDN 遵循主题输出的 `Cache-Control: private, no-store` 与 `Vary: Cookie` 响应头，避免将已解锁页面缓存给其他访客。完整上线验收清单见 [安全审计记录](../security.md#验证记录与部署验收)。
